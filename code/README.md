# DISEÑO DE UNA SOLUCIÓN DE CÁLCULO DE LA CONFIANZA PARA REDES DE NUEVA GENERACIÓN

En este repositorio se encuentran los siguientes archivos:
* **dataset_fuzzy.py**
El cual sirve para generar el conjunto de valores y parámetro Network Trust, con las gráficas y resultados correspondientes.
* **dataset2_fuzzy.py**
El cual sirve para generar el conjunto de valores y parámetro Node Reputation, con las gráficas y resultados correspondientes.
* **Total_Trust.py**
Agrupa y ejecuta los dos programas anteriores sacando por pantalla el parámetro Total_Trust.
* **plot_fuzzy.py**
Gráficos de funciones de membresia para hacer pruebas de diseño.

## Datasets

Datasets generados automaticamente por los programas *dataset_fuzzy.py* y *dataset2_fuzzy.py*
* network_trust_dataset.xlsx
* node_reputation_dataset.xlsx
